Setup and regeneration

Open the Night Orchard VI MIDImix Audio Bridge project in Magic Music Visuals. In Input Sources, choose the physical MIDI Mix on channel 1 and assign the two audio sources to the left and right channels of your audio feed. The Controls tab lists each MIDI assignment and the Globals available for MIDI Learn.

In the project checkout, run make venv once to install the Python dependencies, then make orchard-handbook. Open magic/showcase/edition6/handbook/index.html for the full local edition.

To rebuild the web edition with FFmpeg available, run .venv/bin/python tools/orchard_handbook_pages.py --out /path/to/empty-directory. It uses the saved Magic captures. All web clips are silent. The full local edition includes the additional archive recordings and any available local listening copies.
