# Magic 3.0 features and where they live

Source: the official "What's New In Version 3.0" list in `Contents/MacOS/VersionHistory.txt` and the User's Guide `Contents/MacOS/UsersGuide/Magic_UsersGuide.html`, both shipped with the app (Magic 3.0b6). The online pages on magicmusicvisuals.com sit behind a bot check and were not compared. Tags: *live* = read back from the running app or from a file Magic 3 saved; *saved* = Magic's own saves; *binary* = strings in the app; *guide* = User's Guide or version history only.

## Project file

| 3.0 change | In the file | magicproj |
|---|---|---|
| Syphon/Spout name per project | `Project@videoSharingName` (*live*) | `set --syphon-name`, `Builder(syphon=)` |
| Assets saved relative and absolute | File params keep `value` relative to the project and add `absoluteFilename` (*live*) | `check` resolves both |
| Image module renamed ImageFile | `pluginName="ImageFile"`; old `Image` loads and is re-saved as `ImageFile` (*live*) | `check` warns on `Image` |
| AudioToImage removed | module gone (*binary*: no dylib) | `check` warns |
| Contrast, HueSaturation, Invert, Kaleidoscope, LumaKey, RadialBlur, Fractal now ISF | `.fs` files; Kaleidoscope gains `Zoom`, `Rotation`, `Fill Edges`, loses `Corners` on re-save (*live*) | `catalog` |
| Additive param on color modules | `Additive` on ColorRGB/ColorHSB; old `Premultiply`, `Set` dropped on re-save (*live*) | `catalog`, `check` warns on dropped params |
| Fit Width on Waveform, Spectrum, SineWave | `Fit Width` param (*live*) | `catalog` |
| Multiple waveform/FFT inputs; ISF Overwrite option | `Source` param on Waveform/Spectrum/audio ISF, `Overwrite` on Waveform and multi-input audio ISF (*live*) | `catalog` |
| VideoFile audio output, variable speed | `Audio`, `Audio Gain`, `Speed` (*live*); "Module Audio Output 0/1" Tracks `isInput="0"` without file index (*saved*) | `catalog`; route a source with `route_source` |
| ImageFolder, Lissajous modules | `Folder Reload Cache Scale Index Looping`; `Source 0 Source 1` (*live*) | `catalog` |
| Model lighting, wireframe | `Colorize Wireframe 3-Light Global Light L. Azimuth L. Elevation L. Intensity` (*live*) | `catalog` |
| Antialias MSAA modes | `Quality` (*live*) | `catalog` |
| Multiple audio input devices at once | each `Track` carries its own `deviceName`; any source can point at any device (*saved*) | `set --route SOURCE=DEVICE:CH`, `Builder(audio_device=)` |
| Internals Audio/MIDI Playing, Playback Seeked | Internals feature 10 (*live*) and 11 (*binary*) | `internal:Audio/MIDI Playing` |
| H.264 export: 4:4:4, Quality = CRF, 320 kbps AAC | `RenderSettings quality` 0..10 = CRF 28..18 (*binary*); codec in `format` (codes not mapped) | read via `info`/`decode` |
| Saves | `actualVersion="3"`; `videoSharingNewVer` dropped; every id renumbered on each save (*live*) | `diff` keys nodes by module and position, not id |

Every bundled module's exact Magic 3 params: `magic/magic_modules_v3.json`, saved by Magic 3.0b6 from a project holding all 221 modules with no params (*live*). Magic fills in params a file leaves out.

## App settings, not in the project

Stored in `~/Library/Application Support/MAGIC/MAGIC_1_0.xml`. They are the user's; ask before changing them. That file also holds a secret, so read single keys only (`magicproj.magic_pref`).

- Audio output device and mute (`audioOutputDevice`) (*binary*).
- Clock Source: Window > Magic Window Options > Use Audio Output As Clock Source (`useAudioOutputClock`) (*binary*, *guide*).
- Additional Module Folders, with the 3.0 "V3+ Only" flag per folder (`addtlModuleFolders`) (*guide*; the flag is not visible in current files).
- Fullscreen on a chosen display, Start In Fullscreen, Start Auto-Advance (*guide*).
- Scene Editor Options, including Use ISF Submenu and Increment ISF AI Module Names (*binary* menu).
- ISF AI Prompt window: default model and key (`defaultAIModel`, `promptKey`), temp folder (`promptTempFolder`), "report AI-generated code errors" (*guide*, *binary*).

## UI-only changes

"+" button for new scenes, Scene Group panel (was Folder panel; stored as `SceneTreeItems`), live device hot-plug, fullscreen-per-display menu commands, Syphon/Spout between Magic instances (a SyphonClient with Server "<name> - Magic"), 10 s network timeouts, Apple Silicon build.
